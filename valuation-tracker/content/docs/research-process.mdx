# 研报生产流程

你在这里读到的每一篇研报，都不是「搜索一下再写」的产物，而是由一套**六阶段串行、逐阶段验收**的流水线生产出来的：每一阶段的产出都必须通过验收，不通过就**打回前一环节补充**，绝不跳过、绝不糊弄。下面先看整条流水线长什么样，再逐层展开每个环节为什么这样设计。

整条流水线从信息采集开始，依次经过原文精读、信息处理、交叉验证、信息入库、报告生成，最后归档。每两个环节之间都有一道**阶段验收**：产出不合格就沿虚线打回前一环节补充，直到验收通过才允许进入下一环节。**只有上一环节的产出质量过关，下一环节才有高质量输入可加工**——这正是串行执行与逐阶段验收的意义所在。

每个环节由专门的团队角色负责、各司其职：

| 阶段 | 负责角色 | 产出 | 保证什么 |
|------|---------|------|---------|
| 1 信息采集 | 信息猎手 | 原始素材包 | 三个层级均有实质采集；关键论点有来源可溯；核心数据至少 2 个独立来源 |
| 1.5 原文精读 | 文档精读官 | 精读笔记（含多空论证） | 带着投资目的精读财报 / 研报 / 公告原文，强制覆盖最近 3 个完整财年年报 |
| 2 信息处理 | 信息炼金师 | 结构化数据 | 口径标准化、按三层归类，区分「生意模式数据」与「周期性数据」 |
| 3 交叉验证 | 交叉验证官 | 验证报告 | 逐条置信度评分（1-10）、反共识检验、管理层诚信检查 |
| 4 信息入库 | 知识架构师 | 知识库条目 | 只有高置信度（≥8 分）的信息被沉淀，并完成质量筛查 |
| 5 报告生成 | 报告撰写官 | 最终研报（文字版 + 网页版） | 多空论证综合裁决、增长驱动与护城河可持续性分析、反向检查清单完整 |
| 6 归档 | 系统 | 归档留存 | 每份研报的生产链条可回溯 |

每一篇研报都不是只盯着公司本身，而是把研究对象放在**行业 → 细分行业 → 公司**三层框架里层层聚焦：先看清行业全景与历史参照，再识别真正值得研究的细分赛道，最后落到公司的财务、竞争格局与估值。这样得出的结论才有「上下文」，不会只见树木不见森林。

采集充分性有硬标准：**关键论点至少 1 个权威来源、核心数据至少 2 个独立来源交叉验证**；业绩类数据回法定披露平台核对，**财报原文优先**。如果某一层采集不充分，后续环节会主动补充调研，绝不用单薄素材硬写结论。

研报的可信度，首先来自**读的是原文而不是二手转述**。文档精读官带着投资目的逐字精读财报、研报与公告，围绕增长飞轮、财务状况、竞争格局、管理层质量、风险与逆向检查、历史类比六个方面建立认知，并且**强制覆盖最近 3 个完整财年年报**——只看一年看不出趋势，只看两年看不出连贯。

精读之后必须回答三个问题：**基本面是否逐年变好、三年年报是否连贯、管理层是否诚实**。其中「三年连贯性断裂」或「管理层不诚实」属于**一票否决的 No-Go 红线**：结论不得乐观化，并且会在研报中显式标注，绝不粉饰。

任何一家公司都能讲出一个好故事，也能讲出一个坏故事。为了对抗「先入为主」的偏差，每个结论都基于**同一套原文证据**完成多空双视角论证：多方论证增长飞轮、护城河拓宽、财务质量与估值安全边际，空方论证增长见顶、护城河侵蚀、财务红旗、估值过高与产能过剩 / 地缘风险。双方都必须原文引用、区分事实与观点、预判对方论点并回应、诚实记录本方脆弱点。

写作研报时，再结合**产业理解、行业周期、国际形势、政策形势**等外围因素做最终裁决：多空分歧点显式标注，并给出裁决理由——这就是你看到「为什么最终得出这个结论」的来源。

质量不是事后检查出来的，而是**三层门禁**逐层守出来的：

- **第一层 · 阶段内自检**：每个环节在提交产出前，都要通过自动质量检查，不通过就修正后重新提交——问题在源头被拦住。
- **第二层 · 阶段间验收**：编排者按评分卡验收，从**完整性、准确性、投资视角**三个维度打分（各 0-10 分）：总分低于 24 分直接打回重做；24-28 分有条件通过（标注风险提示）；28-30 分完全通过。
- **第三层 · 发布后复盘**：研报发布后按 7 天 / 30 天 / 90 天时间轴持续复盘——7 天检查是否有事实性质疑，30 天对照期间事件与报告风险提示的吻合度，90 天对比核心预测与实际数据，用结果校准方法。

长期质量指标（每份研报都记账，持续追踪）：

- 来源覆盖率 &gt;90%：关键事实有 ≥2 个独立来源的比例
- 高置信度占比 &gt;70%：置信度 ≥8 分的事实占比
- 四大师框架覆盖率 100%：护城河 / 生意模式 / 反向清单 / 历史类比全部覆盖
- 返工率 &lt;15%：因质量不通过而回退的阶段占比
- 知识复用率 &gt;50%：新研究引用已有知识节点的比例

不是每一次研究都需要走完全量流程。系统会根据主题情况自动选择**最合适的流程模式**：

| 模式 | 适用场景 | 流程差异 |
|------|---------|---------|
| 标准模式 | 全新主题首次研究（默认） | 全量六阶段 + 原文精读 |
| 快速模式 | 知识库已有覆盖且调研时间较近（&lt;90 天） | 精简为单轮采集 + 精读 + 验证 |
| 深度模式 | 重大投资决策前 | 强制四大师评估 + 财报精读全量覆盖 + 回溯 3 年历史数据 |
| 增量模式 | 补充特定公司 / 赛道 | 定向搜索 + 追加写入，复用已有验证结论 |

无论哪种模式，研报生产全程由系统工具链自动支撑：你只需要输入主题、提出疑问、等待一份**可回溯的严谨研报**——每一句结论都能顺着生产链条找到它的出处。
