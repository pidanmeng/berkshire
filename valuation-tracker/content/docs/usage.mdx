# 网站使用指南

估值追踪系统是一块**市值监控看板**：把每一家已经过完整调研的公司的**实时市值**，与调研时给出的**目标市值区间**（悲观 / 合理 / 乐观三档）放在一起对照，让你一眼看出「现在的价格，处在安全边际的什么位置」。

页面左侧的图标列用于切换页面：**首页**（已调研公司看板）、**全市场初筛**（A 股初筛结果）、**暗盘追踪**、**文档**（本指南）与**留言板**。

## 首页 · 公司列表看板

首页顶部是几块统计卡片，相当于整个「篮子」的速览：

- **篮子公司**：当前展示范围内（含标签过滤）已调研公司的总数
- **平均涨跌**：这些公司今日的平均涨跌幅
- **深度低估 / 低估区间**：落在对应安全边际分档的公司数量
- **有估值锚点**：调研已给出三档目标市值的公司数量
- **基本面需更新 / 有基本面更新**：调研时点之后出现新定期报告、提示需要更新的公司数量

统计卡下方是**公司列表**，每一列都是经过设计的监控信息：

| 列 | 含义 |
|----|------|
| 公司 | 公司名称与代码；调研后若出现过基本面更新，名称旁会显示「更新 N」徽标 |
| 行业 / 细分 | 公司所属行业与细分赛道 |
| 现价 / 涨跌 | 最新股价与当日涨跌幅 |
| 总市值 | 当前总市值（亿元） |
| PE-TTM | 滚动市盈率——按最近一年的盈利水平，现价买入需要多少年回本 |
| vs 悲观 / 合理 / 乐观目标 | 当前市值相对三档目标市值的偏离幅度（负值 = 已低于该档目标） |
| 安全边际 | 当前市值所处的分档（见下节） |
| 质量 | 调研时的质量筛查结论：绿 / 黄 / 红三档 |
| 综合分 | 六维评分加权后的综合得分（0-10） |
| 基本面 | 「已最新 / 需更新 / 待检测」——调研后是否有新的定期报告出现 |

点击任意列表头可以**排序**（默认按「距悲观目标」由近到远，即最接近深度低估的公司排在前面）。

左侧的**标签栏**按行业 / 细分 / 公司属性归类，支持多选组合过滤。

**自选股（收藏）**——把重点关注的公司收进自选，随时一键只看收藏列表：

- **星标收藏**：公司列表每一行的最左侧都有星标按钮，点击即可收藏 / 取消收藏
- **只看自选**：标签栏顶部的「自选股」开关打开后，列表只显示已收藏的公司
- **置顶显示**：收藏的公司会固定在列表顶部，优先展示，一眼就能找到重点关注对象
- **两处共用**：暗盘追踪页同样支持星标收藏与「只看自选」过滤，两处共用同一套自选列表——在任意一处收藏 / 取消，另一处同步生效
- **保存在当前浏览器**：自选列表保存在当前浏览器的本地，无需注册或登录；更换设备或清除浏览器数据后收藏会丢失，需要重新收藏

点击列表中的一行即可选中公司：选中一家查看详情，连续选中多家后，主区域会并排展示**横向对比表**，把几家公司的关键指标放在一起比较。

## 安全边际分档怎么读

这是整个看板的核心逻辑：**用当前市值与调研给出的三档目标市值比较**。

| 分档 | 含义 |
|------|------|
| 深度低估 | 当前市值 ≤ 悲观目标——现价已经比「最保守的估计」还低 |
| 低估区间 | 当前市值 ≤ 合理目标，但高于悲观目标 |
| 合理区间 | 当前市值 ≤ 乐观目标，但高于合理目标 |
| 高估区间 | 当前市值 &gt; 乐观目标——现价已超出最乐观的估计 |
| 无估值锚点 | 该调研尚未给出目标市值，无法判断 |

「悲观 / 合理 / 乐观」三档来自研报中基于生意质量、财务与历史参照给出的市值区间，具体推导过程见对应公司的调研笔记。

## 六维评分怎么读

每家公司都从六个维度打分（0-10 分），对应本系统的投资哲学：

- **能力圈**：我们能否真正理解这门生意
- **护城河**：竞争优势是什么、有多宽、能否持续 10 年
- **生意模式**：怎么赚钱、谁付钱、为什么选它
- **管理层诚信**：诚信记录与前后表述的一致性
- **反向清单**：「什么情况下我们会错」的逆向核查是否通过
- **历史类比**：行业与公司的历史参照与时间框架

六维按**固定权重**加权，实时计算得到**综合分**，同一套规则全站一致、不因人而异。雷达图用来快速看清一家公司的「质量结构」——哪项强、哪项弱，一目了然。

## 详情页怎么读

点击公司进入详情，从上到下依次是：

- **一句话判断**：赚谁的钱、赚的是什么钱、为什么投资、为什么不投资——整个调研最浓缩的结论
- **股价走势**：近一年日 K 线，并叠加目标市值参考线，当前位置一目了然
- **安全边际**：当前市值与悲观 / 合理 / 乐观三档目标市值（含换算的每股价格）的对照条，以及相对三档目标的偏离百分比
- **六维评分**：雷达图 + 逐维分数 + 综合分
- **Forward PE 快照**：基于调研时点盈利预测的前瞻市盈率，附估值品种（金融 / 周期 / 资源 / 控股多元集团 / 高成长 / 一般工商 / 亏损）与 **PEG 判读**：PEG &lt; 1 视为低估，1-1.5 匹配，1.5-2 偏高，&gt; 2 显著偏贵
- **基本面更新状态**：「已最新 / 需更新 / 待检测」徽标、最新定期报告标题、调研覆盖的财报期与截止日；需要立即确认时可点击「手动重新检测」

<Callout type="info" title="关于「基本面需更新」标签">
- **标签怎么来的**：系统把调研时记录的**公告截止日**（即研报覆盖到的最新财报 / 公告日期），与之后出现的定期报告公告做对比——截止日之后若出现新的财报，就提示「需更新」；没有新财报则显示「已最新」；缺乏对比信息时显示「待检测」
- **为什么可能不准**：系统里有一部分**早期（存量）调研报告**，生成时并未拉取当时的全部最新财报，记录的覆盖范围可能不完整，导致标签无法准确反映这家公司的基本面到底是不是最新的——例如实际已经缺了最新财报，但标签没有提示「需更新」
- **怎么确认**：以详情页与调研笔记中**实际覆盖的财报期范围**为准——对照公司最新发布的定期报告，看调研是否已覆盖到最近一期；若发现覆盖落后，即可按需发起基本面更新
- **影响范围与现状**：该问题**只可能出现在存量报告**；生产流程已修正约束，之后新生成的报告会完整拉取最新财报，不会再出现此情况
</Callout>
- **调研章节**：估值区间与目标价、跟踪指标、财报精读 10 项检查清单（均为笔记原文）
- **基本面更新**：调研后做过增量复核的公司，这里展示最新研究结论与「上次研究 vs 本次更新」的财务对比图
- **研究报告原文**：两个 Tab——「年报精读」（精读笔记）与「年报原文」（财报原文文本），左侧选文件、右侧读正文
- **调研笔记全文**：完整的公司研究笔记

右上角的「暗盘」与「独立页」是快捷入口，分别打开该公司的暗盘追踪页与独立详情页。

## 全市场初筛页

左侧导航第二项进入**全市场初筛**：从 A 股全市场出发，先做一轮硬性指标过滤，再对候选公司逐只核查财务指标，最后按综合质量**分池**——结果是四类池子：**明星池**（值得重点研究）、**观察池**、**排除池**与**亏损池**。

表格列（综合分 / 市值 / PE / ROE / 营收同比 / 净利同比）均可排序；点击任意一行会展开该公司的**初筛详情分屏**，列出正面亮点、黄色警告与红色红旗，并标注高杠杆等需复核的风险提示，方便你判断是否值得进入正式调研。

## 暗盘追踪

左侧导航第三项进入**暗盘追踪**：一块**全市场暗盘资金监控**看板，用来观察市场短线资金动向。页面数据来自公开市场资金数据，仅用于观察盘面，不带任何调研结论。

- **日期选择 + 查询**：选择任意交易日并点击「查询」，即可查看当天的资金动向
- **统计摘要**：展示所选交易日、当日覆盖的股票数量，以及资金流入 / 流出的家数与金额——一眼看出当天资金的整体多空力量
- **表格列**：代码 / 名称 / 暗盘资金 / 明盘资金 / 主力净流入 / 活跃度 / 股价 / 涨幅 / 板块；红涨绿跌，各列均可点击表头排序，表格支持分页浏览
- **搜索**：按代码或名称输入，快速定位到目标个股
- **自选联动**：表格自带星标收藏，配合「只看自选」开关，只盯自己关注的股票（与首页共用同一套自选列表）

点击表格中的**公司名称**，进入该公司的**暗盘历史页**：展示近期暗盘资金与主力净流入的走势图、涨幅走势，方便回溯一只股票短线的资金变化。详情页右上角的「暗盘」快捷入口打开的就是同一页面。

<Callout type="info" title="怎么看暗盘数据">
暗盘资金反映的是**短线资金动向**，波动快、噪音多，**不代表公司基本面好坏**，仅供参考，不要据此做长期买卖决策。
</Callout>

## 数据时效

- **行情**：实时行情每 60 秒自动刷新。
- **基本面**：笔记内容在**调研时点**定格。若调研截止日之后公司发布了新的定期报告，列表会把该公司标记为「需更新」并列出具体报告；更新后的增量研究会以「基本面更新」的形式补充展示。需要注意的是，**存量报告**的覆盖范围可能不完整，「需更新」标签仅供参考，最终以笔记中实际覆盖的财报期为准。
- 行情数据来自公开数据源，可能滞后或出错；调研结论基于公开信息，仅供参考。
