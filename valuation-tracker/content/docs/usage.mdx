# 网站使用指南

估值追踪系统（Valuation Tracker）是一个**市值监控终端**：监控已调研公司的实时市值 vs 目标市值（安全边际），并按标签归类展示财务状况、股价走势与基本面更新状态。

## 系统架构与数据流

```
Next.js 15（纯 UI/SSR，端口 3000）   ←→   Elysia 后端（Bun，端口 3001）
```

- **Markdown 公司笔记是唯一事实源**：后端读取 `Research/10-Knowledge/**/02-公司研究/` 下的公司笔记，请求时解析 frontmatter（60 秒缓存）。
- **综合评分不人工给出**：由六维评分（能力圈/护城河/生意模式/管理层诚信/反向检查清单/历史类比）按权重加权**现算**，前端展示、评估脚本与回填脚本共用同一个公式文件。
- **数据库只存动态状态**：价格快照、基本面检测缓存等运行时数据；调研内容不落库。

## 首页（公司列表看板）

最左侧是页面导航列（首页 / 全市场初筛 / 文档），点击即可切换。

主看板采用**可拖拽分割布局**（左中右三面板）：

- **标签侧栏**：按标签（行业/细分/公司属性）筛选公司，支持多选组合过滤。
- **公司列表**：展示每家公司的最新行情、综合分、安全边际分档、Forward PE、质量筛查结论（绿/黄/红）、一句话判断（为什么投 / 为什么不投）等。
- **主内容区**：点击某家公司后显示详情（详见下节）；支持多选进入**横向对比**模式。

### 安全边际分档（核心监控逻辑）

当前市值 vs 目标市值（公司笔记 frontmatter 的 `target_market_cap_yi`，亿元）：

| 分档 | 条件 |
|------|------|
| 深度低估 | 当前市值 ≤ 悲观目标 |
| 低估区间 | 当前市值 ≤ 合理目标 |
| 合理区间 | 当前市值 ≤ 乐观目标 |
| 高估区间 | 当前市值 > 乐观目标 |
| 无估值锚点 | 无目标市值数据 |

### 六维评分雷达

详情中的雷达图展示六个维度（能力圈 / 护城河 / 生意模式 / 管理层诚信 / 反向清单 / 历史类比）的打分，帮助快速判断公司的**质量结构**：护城河是否够宽、生意模式是否清晰、管理层是否诚信。

## 详情页

点击公司后，主内容区展示该公司详情，包含：

- **实时行情**：现价、涨跌幅、PE/PB/PS/PCF、市值
- **目标市值条**：悲观 / 合理 / 乐观三档锚点与当前位置（安全边际可视化）
- **六维评分**：雷达图 + 逐维说明
- **Forward PE 与 PEG**：估值快照与 PEG 判读（&lt;1 低估 / 1-1.5 匹配 / 1.5-2 偏高 / >2 显著偏贵）
- **财务对比图**：与同行公司的关键财务指标对比（ECharts 可视化）
- **K 线图**：近 N 日股价走势
- **公司笔记全文**：调研结论、财务分析、护城河评估、风险与反向检查清单
- **研报原文 Tab**：年报精读（deep-read）与年报原文浏览

## 全市场初筛页

左侧导航第二项进入**全市场初筛**：基于 A 股全市场快照与逐只财务指标，经过三级漏斗（快照硬过滤 → 逐只指标 → 分池评分）筛出值得研究的标的池，结果直接接入本页面看板。

## API 说明

后端 API（前缀 `/api`，默认经 Next 路由代理转发到 Elysia）：

| 端点 | 说明 |
|------|------|
| `GET /api/health` | 健康检查 |
| `GET /api/companies` | 全部公司 + 实时行情 + 安全边际分档 + 基本面检测缓存（60s TTL） |
| `GET /api/companies/:thscode` | 单公司详情（含笔记全文、六维评分、Forward PE、调研截止） |
| `GET /api/kline/:thscode?days=` | 近 N 日 K 线（60s TTL） |
| `GET /api/quotes` | 行情轮询（60s TTL，快照入库） |
| `GET /api/fundamentals/:thscode?refresh=1` | 巨潮公告检测：调研截止日之后是否出现新定期报告（6h TTL） |

## 数据时效

- 行情数据为**实时/轮询快照**，价格每 60 秒刷新。
- 基本面（笔记内容）在**调研时点**定格，公司笔记 frontmatter 的 `research_cutoff`（财报期 + 公告截止日）用于判断基本面是否需更新；若调研截止后出现新定期报告，列表会提示「需要更新」。

## 本地启动

```bash
cd valuation-tracker
bun run dev   # 并行启动 Elysia(3001) + Next(3000)
```

打开 http://localhost:3000 即可访问。
