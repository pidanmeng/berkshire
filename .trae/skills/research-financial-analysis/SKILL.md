# 财报精读与深度分析 Skill

## 能力范围

对目标公司进行财务报表的深度分析，超越「看数字」层面，识别数字背后的经营真相：

- **利润表分析**：收入质量、利润含金量、费用结构、增长驱动
- **资产负债表分析**：资产结构、负债风险、营运资本、隐形资产/负债
- **现金流量表分析**：经营现金流质量、自由现金流、资本开支合理性
- **杜邦分析**：ROE 拆解，识别驱动因素变化
- **盈利质量识别**：应收账款异常、存货异常、关联交易、利润操纵信号
- **同业对比**：与 2-3 家同行对比关键指标

## 分析框架

### 1. 利润表精读

**收入增长质量**：
- 收入增长来自内生还是并购？（看商誉变化、投资收益）
- 收入增长是否伴随现金流入？（经营现金流/营业收入 是否稳定）
- 季节性是否正常？（Q1-Q4 分布是否合理）

**毛利率分析**：
- 毛利率趋势：上升（定价权增强）/ 稳定（护城河稳固）/ 下降（竞争加剧）
- 与同行对比：高于/低于行业平均？差距在扩大还是缩小？

**费用率分析**：
- 销售费用率：是否需持续高投入维持收入？
- 管理费用率：规模效应是否显现？
- 研发费用率：技术驱动型行业是否投入足够？

**利润含金量**：
- 经营现金流 / 净利润 的比值：持续 >1 为佳
- 净利润中「非经常性损益」占比：过高则利润质量差

### 2. 资产负债表精读

**资产结构**：
- 流动资产 / 总资产：轻资产还是重资产？
- 应收账款 / 营业收入：是否异常上升？（可能暗示渠道压货）
- 存货 / 营业成本：周转是否变慢？（可能暗示滞销）
- 商誉 / 净资产：并购驱动增长的风险
- 固定资产 / 总资产：资本密集度

**负债与偿债能力**：
- 有息负债 / 总资产：杠杆水平
- 流动比率、速动比率：短期偿债能力
- 利息覆盖倍数：经营利润能否覆盖利息

**营运资本**：
- 现金转换周期 = 存货周转天数 + 应收账款周转天数 - 应付账款周转天数
- 趋势：缩短（效率提升）/ 延长（占用资金增加）

### 3. 现金流量表精读

**经营现金流**：
- 经营现金流净额是否持续为正？
- 经营现金流 / 净利润：持续 <1 需要警惕
- 现金流波动是否与利润波动一致？

**投资现金流**：
- 资本开支 / 折旧摊销：维持性资本开支 vs 扩张性资本开支
- 投资支出是否带来相应回报？（看后续收入增长）

**筹资现金流**：
- 是否依赖外部融资？（频繁借款或增发）
- 分红 / 净利润：分红政策是否稳定？

### 4. 盈利质量红线（预警信号）

| 信号 | 含义 | 检查方法 |
|------|------|---------|
| 经营现金流长期 < 净利润 | 利润可能虚增 | 对比 3-5 年历史 |
| 应收账款增速 > 收入增速 | 渠道压货或放宽信用 | 计算两者增长率 |
| 存货增速 > 成本增速 | 产品滞销 | 计算周转天数变化 |
| 商誉/净资产 > 30% | 并购风险大 | 看商誉减值历史 |
| 毛利率异常高于同行 | 可能财务操纵 | 同业对比 |
| 关联交易收入占比高 | 独立性存疑 | 看年报关联交易披露 |
| 频繁变更会计政策 | 可能调节利润 | 看年报会计政策章节 |
| 审计意见非标准无保留 | 重大问题 | 直接排除或深度调查 |

### 5. 归因分析框架（数据为什么是这样）

> 归因分析回答「数据为什么是这样」，是精读的核心延伸：对显著的数据现象（指标大幅波动、利润结构异常、数据间勾稽矛盾）必须归因，且**凡有结论必有证据**（财报原文出处 + 外部来源 URL/时点），禁止臆测。

#### 5.1 扣非净利润拆解方法论

扣非净利润 = 归母净利润 − 非经常性损益。差距大时（差额 ≥ 归母净利 10% 或扣非方向与归母背离），逐项拆解非经常性损益并判断持续性：

| 项目 | 解读 | 持续性判断标准 |
|------|------|---------------|
| 政府补助 | 计入当期损益的政府补助 | 与主业经营挂钩、逐年稳定 = 经常性；一次性大额 = 一次性 |
| 投资收益（理财/联营） | 处置长期股权投资、理财收益、联营企业贡献 | 理财收益波动大；处置子公司/股权 = 一次性 |
| 公允价值变动损益 | 交易性金融资产/负债市值波动 | 市场行情驱动，不可持续，多为一次性 |
| 资产处置损益 | 处置固定资产/无形资产/长期股权投资 | 偶发，一次性 |
| 汇兑损益 | 外币货币性项目折算 | 汇率波动，周期性强、不可控 |
| 营业外收支 | 捐赠、罚款、债务重组、政府拆迁补偿 | 偶发，一次性 |

判定原则：与主业相关且可重复 = 经常性；偶发、不可持续 = 一次性。**扣非净利远低于归母净利、或归母净利增长完全由非经常性驱动，必须警示盈利质量。**

#### 5.2 指标波动归因四步法

对毛利率/净利率/ROE/营收/经营现金流 同比或环比变动 ≥2pp 或方向逆转，按四步归因：

1. **量价拆分**：销量 vs 单价，谁在动？量增价跌 / 量平价升 / 量价齐跌
2. **成本传导**：原材料/人工/能源/运费占比变化，BOM 中原材料价格敏感度；单位成本上行是否可向下游传导
3. **结构与格局**：产品/客户/地区结构变化；是价格战（竞对降价）还是主动提价/降价（换份额）
4. **周期 vs 结构**：波动是行业周期（大宗价格、库存周期）还是结构性变化（技术替代、份额转移）

**证据要求**：用 Trae 自带搜索工具（系统 websearch / webfetch + research-web-search skill）寻找外部证据——原材料价格指数、行业价格战新闻、同行毛利率对比、管理层电话会/调研纪要；每条证据标注来源 + 时点；证据不足的归因显式标注「证据不足，置信度 ≤6」。

#### 5.3 良性 vs 恶性判定表

| 现象 | 良性 | 恶性 |
|------|------|------|
| 毛利率↓ | 主动让利换份额（量增价跌、份额升）、成本短期上行可向下游传导、一次性因素 | 价格战且份额流失、成本无法传导、结构性恶化（产品同质化） |
| 毛利率↑ | 定价权/结构升级、成本下行 | 提价脱离需求、靠低毛利砍单粉饰 |
| 归母净利↑ 靠非经常性 | — | 主业盈利恶化，靠一次性收益支撑 |
| 营收↑ 但现金流↓ | 季节性回款、扩产备货 | 放宽信用、渠道压货、收入确认激进 |

#### 5.4 数据逻辑一致性检查表（8 项勾稽）

逐项核对数据间逻辑，不一致处标注「逻辑断裂点」并追因：

| # | 勾稽项 | 判读口径 | 追因指引 |
|---|--------|---------|---------|
| 1 | 营收增速 vs 经营现金流增速 | 营收增而现金流降 → 含金量存疑 | 放宽信用？票据结算增加？收入确认激进？ |
| 2 | 应收增速 vs 营收增速 | 应收增速 > 营收增速 → 渠道压货/放宽信用 | 客户结构？账期变化？坏账风险？ |
| 3 | 存货增速 vs 营业成本增速 | 存货增速 > 成本增速 → 滞销/跌价风险 | 备货节奏？订单取消？跌价准备？ |
| 4 | 归母净利增速 vs 扣非净利增速 | 归母升而扣非降 → 非经常性驱动 | 见 5.1 拆解 |
| 5 | 毛利率 vs 单价/单位成本 | 毛利率变化应与量价成本自洽 | 见 5.2 归因四步 |
| 6 | 净利润 vs 经营现金流 | OCF/NI < 0.8 持续 → 利润含金量差 | 利润确认 vs 现金回收错位 |
| 7 | 管理层归因表述 vs 数据 | 管理层解释与数字是否吻合 | MD&A 与三表对照，前后口径是否一致 |
| 8 | 营收 vs 产能/销量 | 营收增长是否有产量/产能支撑 | 单产、产能利用率、新产能爬坡 |

#### 5.5 归因证据信源指引

- **原材料价格指数**：行业数据站（如电池行业碳酸锂/六氟磷酸锂价格、钢铁行业铁矿石/焦炭、养殖行业猪价/饲料），Mysteel/卓创/生意社等
- **行业新闻/价格战报道**：财联社、第一财经、证券时报、每经（B 类，需多方交叉）
- **同行财报毛利率**：用 `evaluate.ts --peer <同行代码>` 获取同业对比（财报原文优先）
- **管理层电话会/调研纪要**：公司投资者关系页、互动易/上证e互动、券商纪要
- 来源可信度沿用本 Skill 内分级：A 类权威（交易所/官方/公司财报）/ B 类财经媒体/研报 / C 类行业站/自媒体

### 6. 杜邦分析

```
ROE = 净利润率 × 资产周转率 × 权益乘数
```

拆解后分析：
- ROE 提升来自哪个因素？（盈利能力/运营效率/杠杆）
- 与同行对比各因素差异
- 趋势：ROE 是否在可持续的路径上？（避免靠加杠杆提升 ROE）

## 使用方式

Agent 在分析公司财务时，调用此 Skill 加载分析框架，然后：
1. 使用共享脚本 `evaluate.ts` 获取财务三表数据（财务数据 API 由公共库 `hithink.ts` 提供）
2. 搜索 2-3 家同行数据进行对比
3. 按上述框架逐条分析并输出 Markdown

也可以直接运行脚本：`bun run .trae/skills/research-financial-analysis/scripts/deep-dive.ts --code 600519`
