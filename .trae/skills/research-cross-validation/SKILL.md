# 交叉验证 Skill

## 能力范围
- 多源事实比对（同一事实在不同来源间的一致性）
- 矛盾点标记与倾向判断
- 置信度评分（1-10）
- 反共识独立思考（检验结论是否被市场一致预期裹挟）

## 置信度评分标准
| 分数 | 含义 | 判定条件 |
|------|------|---------|
| 9-10 | 高置信 | ≥3 个 A/B 级独立来源一致 |
| 7-8 | 较可信 | 2 个独立来源一致 或 1 个权威来源 + 间接佐证 |
| 5-6 | 中等 | 单一来源但可信 或 部分一致（**独家数据**单源但可信度高的可按此档，不强行凑源） |
| 3-4 | 存疑 | 来源矛盾或口径不明 |
| 1-2 | 弃用 | 单一低质来源、无法核实 |

## 执行步骤
1. 读取 processed 文件中的关键事实清单
2. 对每条事实收集多源证据（核心数据 ≥2 独立来源；关键论点尽量多视角；独家数据单源可接受但置信度上限 6）
3. 按「来源权威性 × 时点新鲜度 × 独立性」计算一致性
4. 评分并标记状态：通过 / 需补充 / 存疑 / 弃用
5. 对矛盾点：呈现双方观点 → 分析分歧根源（口径/时点/利益立场）→ 给倾向与依据
6. 执行反共识检验：市场共识是什么？有无被忽略的信号？相反假设是否成立？
7. 输出验证表 + 高置信度清单 + 可写入知识库清单

## 输出格式
```markdown
| 事实陈述 | 来源1 | 来源2 | 来源3 | 一致性 | 置信度 | 状态 |
|---------|-------|-------|-------|--------|--------|------|

> ⚠️ **矛盾**: 来源A称X，来源B称Y
> - 倾向: 来源A（依据: ...）
> - 建议: ...
```

## 注意事项
- 独立来源判定：不同媒体转载同一原始报道不算独立来源
- 数字要还原到原始口径再比较（避免比较未换算的数值）
- 结论只写给分≥8 的事实；低分事实必须在报告中显式标注存疑
- 保持客观：发现矛盾时呈现多方观点，不做简单取舍
