# 四大师投资框架评估 Skill

## 能力范围

以「价值投资」四大师哲学为底层，对目标公司进行结构化评估：

- **巴菲特框架**：护城河评估、称重机（内在价值）、能力圈判断、安全边际
- **芒格框架**：反向检查清单、多元思维模型、激励一致性、心理学偏差识别
- **段永平框架**：本分（管理层诚信）、生意模式评价、做对的事情、不做空不借钱
- **李录框架**：文明趋势/结构性机会、历史类比、时间框架判断

## 评估维度

### 1. 能力圈评估（巴菲特）

判断你是否真的理解这家公司：

| 检查项 | 通过标准 |
|--------|---------|
| 能描述商业模式 | 用一句话说清「怎么赚钱」 |
| 能预测 10 年后 | 对 10 年后的行业格局有合理判断 |
| 能评估竞争 | 知道主要竞争对手及各自优劣 |
| 理解财务驱动 | 知道 ROE 的杜邦分解，知道利润从哪里来 |

**结论**：如果 4 项中通过 <3 项，标注「超出能力圈」，整体置信度不超过 7。

### 2. 护城河评估（巴菲特）

| 护城河类型 | 识别标志 | 量化指标 |
|-----------|---------|---------|
| 成本优势 | 全行业最低成本 | 毛利率高于同行 5pct+，且持续 |
| 品牌/定价权 | 可提价而不丢份额 | 毛利率稳定或上升，销量不降 |
| 网络效应 | 用户越多价值越大 | 用户增速 vs 获客成本趋势 |
| 转换成本 | 客户换供应商代价高 | 客户留存率 >90% |
| 规模效应 | 越大越便宜 | 营收增长时费用率下降 |
| 牌照/特许 | 政策壁垒 | 准入门槛高，替代品少 |

**评分**：
- 无护城河：0-2 分
- 窄护城河（3-5 年）：3-5 分
- 宽护城河（5-10 年）：6-8 分
- 极宽护城河（10 年+）：9-10 分

### 3. 生意模式评估（段永平）

好生意模式的特征：

| 维度 | 好生意 | 坏生意 |
|------|--------|--------|
| 现金流 | 经营现金流 > 净利润，且稳定 | 经营现金流长期 < 净利润 |
| 资本需求 | 轻资产，ROIC 高 | 重资产，需持续大额资本开支维持地位 |
| 增长方式 | 内生增长，不稀释股权 | 频繁并购、增发、举债扩张 |
| 客户粘性 | 复购高，转换成本高 | 一次性交易，价格敏感 |
| 定价权 | 可自主定价 | 价格接受者 |
| 杠杆 | 低负债，现金流可覆盖投资 | 高负债，依赖外部融资 |

**一票否决项（段永平「本分」原则）**：
- 管理层有诚信问题（虚假陈述、大股东侵占、频繁关联交易）
- 公司参与不道德或灰色业务
- 商业模式依赖持续「骗」客户或供应商

### 4. 反向检查清单（芒格）

对每家公司回答以下问题：

1. **失败情景**：这家公司 5 年内最可能失败的原因是什么？
2. **历史错误**：管理层过去 5 年做过什么错误决策？代价多大？
3. **激励冲突**：高管薪酬是否与股东长期利益一致？有无大额减持？
4. **行业黑天鹅**：该行业历史上出现过什么毁灭性事件？会重演吗？
5. **财务地雷**：有息负债/总资产 >50%？商誉/净资产 >30%？经营现金流连续 2 年 < 净利润？
6. **竞争侵蚀**：护城河是否在变窄？新进入者/替代品威胁如何？
7. **心理偏差**：市场当前对该公司的共识是否存在集体误判？

### 5. 历史类比（李录）

- 海外/历史上是否有类似行业/公司的案例？
- 当时的市场共识是什么？后来如何演变？
- 当前中国处于类比中的哪个阶段？
- **时间框架判断**：这是一个 1 年周期的机会，还是 10 年结构性的机会？

## 使用方式

Agent 在分析公司时，调用此 Skill 加载评估框架，然后：
1. 使用共享脚本 `evaluate.ts` 获取公司财务数据
2. 使用 `research-web-search` Skill 搜索管理层历史、行业风险等信息
3. 按上述框架逐条评估并输出 Markdown
