# 数据提取 Skill

## 能力范围
- 表格解析与关键指标提取（营收、净利润、毛利率、ROE、市占率等）
- 时间序列识别（历史数据对齐到年份/季度）
- 单位与口径标准化（万元/亿元、美元/人民币、GAAP/Non-GAAP）
- 提取结果带来源锚点，保证可追溯

## 执行步骤
1. 读取原始材料（网页文本、PDF 内容、表格、财报片段）
2. 识别实体与指标：公司名、指标名、数值、单位、时点、口径
3. 指标口径判定：
   - 数值口径：合并报表/母公司、含少数股东/不含、扣非/不扣非
   - 时间口径：财年/自然年、同比/环比、期末/平均
   - 货币口径：本币/外币、汇率基准日
4. 统一单位换算（示例：万元 → 亿元 ÷10000；美元 → 人民币 ×汇率）
5. 填充结构化模板并保留每条数据的原始出处
6. 标记提取置信度：直接引用=高；间接推算=中；缺失=需补充

## 输出格式
```markdown
## 关键指标表
| 指标 | 数值 | 单位 | 时点 | 口径 | 来源 |
|------|------|------|------|------|------|

## 标准化说明
- 单位换算: ...
- 口径调整: ...
```

## 注意事项
- 数值必须保留「单位」和「时点」两个维度，缺一不可
- 表格中空单元格不要臆测填充，标注「—」
- 多个来源数值不一致时并列保留，标注差异，不要平均
- 涉及预测值时标注「预测」并给出预测主体
