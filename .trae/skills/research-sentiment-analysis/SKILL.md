# 情绪分析 Skill

## 能力范围
- 情感极性判断（正面 / 中性 / 负面）
- 情绪强度评分（1-10）
- 关键观点提取（支持方 / 反对方 / 观望方）
- 情绪时间线（情绪是否在变化、拐点在哪）

## 执行步骤
1. 采集观点样本（研报观点、媒体报道、社区讨论、卖方/买方立场）
2. 对每条观点标注：主体、立场、强度、时点、依据
3. 汇总情绪分布：正/中/负占比，主流预期是什么
4. 识别情绪分歧点与拐点信号
5. 区分「事实性信息」与「观点性信息」：情绪分析只作用于观点层
6. 输出 YAML 数据块 + Markdown 摘要

## 输出格式
```yaml
sentiment:
  overall: "偏多"        # 偏多 / 中性 / 偏空 / 分歧
  polarity: 0.6          # -1.0 至 +1.0
  intensity: 7           # 1-10
  bull_views: 12
  bear_views: 5
  neutral_views: 8
  shift: "改善"          # 改善 / 恶化 / 持平
  shift_trigger: "事件X"
```

## 摘要结构
```markdown
## 情绪摘要
- 整体: 偏多（极性 0.6，强度 7/10）
- 多空比: 12:5（空头核心论点: ...）
- 分歧点: ...
- 情绪拐点: 事件X → 情绪由A转B
```

## 注意事项
- 情绪 ≠ 事实：情绪分析结果不能作为数据事实写入知识节点
- 标注样本量与代表性（样本不足时降低结论强度）
- 区分机构观点与散户观点，权重不同
- 提示情绪极端化风险（一致性过高往往是反向指标）
