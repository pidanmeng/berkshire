# 笔记整合 Skill

## 能力范围
- MOC（Map of Content）索引页生成与更新
- 反向链接检查与补全
- 孤立节点检测（无入链、无出链的笔记）
- 断链检测与修复

## 知识库三段式目录（MOC 依据）
```
10-Knowledge/XX-一级行业/
├── 00-行业概览/     # 行业全景、产业链、政策
├── 01-细分行业/     # 细分行业分析
└── 02-公司研究/     # 公司概览、财务、竞争格局
```

## 执行步骤

### 1. 更新 MOC
1. 扫描 `Research/10-Knowledge/00-MOC/` 下的行业 MOC 页
2. 用 glob 扫描 `10-Knowledge/01-新能源/` 等目录的实际文件（含三段式子目录）
3. 将新笔记按层级插入对应 MOC 分类：
   - `00-行业概览/` → 「行业概览」小节
   - `01-细分行业/` → 「细分行业」小节（按细分分组）
   - `02-公司研究/` → 「公司研究」小节
4. 更新 `行业总览-MOC` 与 `updated` 字段

### 2. 检测孤立节点
1. grep 全库 `\[\[(.*?)\]\]` 提取链接关系
2. 找出没有任何入链的知识节点（潜在孤立节点）
3. 判断其归属行业与层级（概览/细分/公司），通过正文引用 / properties 关联将其连入图谱

### 3. 修复断链
1. 提取所有 `[[链接]]` 与库内实际文件名比对
2. 断链处理：目标文件是否存在 → 不存在则尝试匹配模糊名（按目录/前缀）
3. 无法修复的断链改为纯文本并加 `%% 断链: 目标不存在 %%` 注释，勿伪造文件
4. 输出修复报告：修复数 / 断链数 / 建议

## 输出格式
```markdown
## 图谱优化报告
- 扫描笔记数: N
- 修复断链: X 处
- 孤立节点: Y 个
  - 已关联: ...
  - 建议手动处理: ...
- MOC 更新: 行业-MOC（+Z 条链接）
```

## 注意事项
- 不创建空壳笔记来「消除」断链；链接目标必须真实存在或有明确创建计划
- 修改文件时只增删链接相关部分，保留原内容与格式
- 孤立节点需人工判断价值后再决定是否保留
- 每次知识架构师交付后运行一次；用户可用 `/sync-links`、`/update-moc` 手动触发
- MOC 分类必须与三段式目录一一对应
