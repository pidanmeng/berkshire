## 四大师投资哲学指引（报告阶段）

报告不是信息的堆砌，而是「投资决策支持文档」。所有结论必须围绕以下框架展开：

- **巴菲特（护城河与安全边际）**：
  - 核心结论必须回答：这些公司的护城河是什么？有多宽？是否在变窄？
  - 估值部分必须提供「称重」视角——当前价格相对于内在价值处于什么位置？给出三情景（悲观/中性/乐观）估值区间与目标买入/卖出价区间
  - 安全边际：指出在什么条件下这些投资论点会被推翻

- **芒格（检查清单与心理学）**：
  - 报告必须包含「反向检查清单」——投资这家公司/行业的最大风险是什么？什么情况下我们会错？
  - 识别市场心理偏差：当前市场共识是否存在集体误判？（过度乐观/悲观、锚定效应、从众心理）

- **段永平（本分与做对的事情）**：
  - 报告结论用「关注/跟踪/了解」等客观表述，避免「强烈买入/卖出」等不本分的措辞
  - 强调「做对的事情」——如果生意模式不好或管理层不诚信，直接指出「不值得继续跟踪」
  - 跟踪指标：为每家公司设定与投资论点直接挂钩的核心跟踪指标（可观测、有阈值，数量不是重点），未来据此判断投资论点是否仍然成立

- **李录（结构性机会与时间框架）**：
  - 报告必须明确「时间框架」——这是一个 1 年内的周期性机会，还是一个 10 年维度的结构性机会？
  - 历史类比：当前行业/公司状况与历史上哪个案例最相似？那个案例后来如何演变？

## 增长驱动与核心优势可持续性分析（报告阶段强制章节）

> 每份报告必须回答以下两个问题组，结论基于 deep-read（增长飞轮/财务深度/多空论证）与 validated 数据，不得凭空推断；无法回答的项显式标注「证据不足」并给出置信度。

### 问题组 A：增长驱动分析（当前高增长能否持续、未来靠什么增长）

对每家代表公司逐项回答：

1. **企业当前是否处于高增长阶段？** 用营收/归母净利/扣非净利增速（含三年序列）判断：高增长 / 中低速增长 / 负增长，并说明增速口径与驱动总量
2. **当前的高增长是由哪些原因促成的？** 量价拆分（量增还是价增？）、产品/客户/地区结构、产能释放、新业务贡献、并购并表、行业景气、政策红利——逐项量化并附证据
3. **未来有哪些其他因素可能促成企业高增长？** 第二曲线、新产品/新客户导入、产能投放、出海、行业渗透率提升、政策催化——区分「已兑现」与「待验证」
4. **这些因素是内因还是外因？企业是否能主导？**
   - **内因**（企业可主导）：产品创新、产能扩张、客户拓展、成本优化、渠道建设、管理改善 → 持续性较强
   - **外因**（企业不可主导）：行业景气、需求周期、政策补贴、原材料价格、竞争格局 → 持续性存疑，需判断暴露度与对冲能力
   - 结论：未来增长中「可主导的内因」占比越高，成长确定性越强；纯外因驱动的增长要在报告中标注周期风险
5. **高增长的可持续性判断**：当前高增长的驱动因素是否可持续（内因/外因占比）、边际增速变化信号（环比、订单、合同负债）、对应跟踪指标（增速阈值）

### 问题组 B：核心优势可持续性分析（企业相对同行的优势能否维持）

> 企业当前突出的经营表现（高毛利、高 ROE、高增速、高份额、成本领先、技术领先等——**不限定具体指标，按企业实际突出的维度选**）必须按以下框架逐项回答；下面以「毛利率优势」为例示意，实际分析以该企业真正突出的优势维度为准：

1. **企业相对行业/同行的核心优势是什么？** 识别企业真正突出的 1-3 个优势维度（毛利率、净利率、ROE、营收增速、市占率、成本、技术/专利、品牌、客户粘性、渠道、资源/牌照等），每个维度量化差距（pp 或倍数）
2. **为什么会有这个优势？** 归因拆分：成本优势（规模/工艺/原材料掌控/垂直一体化）、品牌溢价与定价权、产品结构（高价值品类占比）、技术壁垒（专利/认证/独家供应）、网络效应/转换成本、地理位置/资源禀赋/政策牌照——逐项附证据
3. **优势是否能够维持（或继续扩大）？** 判断优势趋势：扩大 / 高位稳定 / 收窄，基于三年序列 + 最新季度；明确影响该优势的核心变量
4. **有哪些因素可能导致优势被侵蚀？** 成本传导（原材料/人工）、行业价格战/产能过剩、产品结构恶化、竞争者涌入（技术扩散）、技术路线迭代、汇率、客户压价（集中度）、政策变化——逐项评估发生概率与影响幅度
5. **公司有什么独特的壁垒，能保持比同行更强的优势？** 明确「护城河 → 优势溢价」的因果链：什么结构性壁垒让同行无法复制（独家工艺/专利/品牌心智/转换成本/资源独占），该壁垒的可持续年限
6. **优势敏感性**：该优势每收窄 N pp（或每下降 N%）对净利率/利润的影响幅度，作为风险提示与安全边际参考

> 报告结构中的「代表公司分析」必须包含以上两组分析；行业级报告在「行业分析」中给出行业整体盈利水平与竞争格局，公司级在代表公司章节展开。
