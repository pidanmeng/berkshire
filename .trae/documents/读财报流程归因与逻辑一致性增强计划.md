# 读财报流程增强计划：数据归因与逻辑一致性核查

> 目标：在现有财报精读流程（Phase 1.5 DocumentReader）基础上，把「数据背后的原因与趋势」「数据间不合逻辑之处的挖掘与追因」「凡有结论必有证据」固化为**强制精读目标**，并贯通到下游消费方（Phase 3 CrossValidator 验证、Phase 2 InfoAlchemist 提取）。

---

## 一、摘要

当前精读流程只解决「数字是什么」，不强制回答「数字为什么是这样」。本次增强新增**第 9 大精读目标「数据归因与逻辑一致性核查（强制）」**，含三个子模块：

1. **9.1 扣非净利润归因拆解** — 归母净利润 vs 扣非净利润差距大时，逐项拆解非经常性损益，判断每项是否可持续。
2. **9.2 核心指标波动归因（需外部证据）** — 毛利率/净利率/ROE 等大幅波动时，按量价/成本/结构/竞争/周期四步归因，判定良性/恶性；**必须用 Trae 自带搜索工具（websearch/webfetch + research-web-search skill）找外部证据**，禁止臆测，证据不足必须显式标注。
3. **9.3 数据逻辑一致性检查** — 8 项强制性数据勾稽，挖掘「不合逻辑」之处并追根溯源。

下游配套：CrossValidator 专项验证归因结论与逻辑断裂点；InfoAlchemist 核心指标提取新增扣非字段；AGENTS.md 编排器验收清单同步。

## 三、改动方案（逐文件）

### 3.1 `.trae/agents/document-reader.md`（核心改动）

**a. 工作原则新增第 8 条**：
> 8. **凡有结论必有证据**。归因性结论（如「毛利率下滑因价格战」「扣非差距因大额政府补助」）必须附证据链：财报原文出处（页码/章节）+ 外部来源（URL + 时点）；证据不足的归因显式标注「证据不足，置信度 ≤6」，禁止想当然。

**b. 精读目标清单新增第 9 项**（放在第 8 项三年年报之后）：

```
### 9. 数据归因与逻辑一致性核查（强制）
> 任何显著的数据现象（指标大幅波动、利润结构异常、数据间勾稽矛盾）都必须「归因 + 挖不合逻辑处 + 追因」。

9.1 扣非净利润归因拆解
- 归母净利润 vs 扣非净利润：计算差额及占比（差额 ÷ 归母净利）
- 从财报「非经常性损益明细表」+ 附注逐项拆解差额来源：政府补助 / 投资收益（理财、联营）/ 公允价值变动损益 / 资产处置损益 / 汇兑损益 / 营业外收支 / 其他
- 对每个主要项目（单项 ≥ 差额 10% 或金额显著）判断持续性：经常性（与主业相关、可重复）vs 一次性（偶发、不可持续）
- 结论：利润主要靠经常性还是非经常性驱动？扣非后盈利质量如何？扣非净利远低于归母净利时必须警示
- 关键证据：非经常性损益明细表、附注、现金流量表补充资料

9.2 核心指标波动归因（需外部证据）
- 触发条件：毛利率 / 净利率 / ROE / 营收 / 经营现金流 同比或环比变动 ≥2pp 或方向逆转
- 归因四步：① 量价拆分（销量 vs 单价，谁在动）② 成本传导（原材料/人工/能源/运费，BOM 占比）③ 结构与格局（产品/客户/地区结构；价格战 vs 份额变化）④ 周期 vs 结构定位
- 良性 / 恶性判定：按 research-financial-analysis SKILL「良性/恶性判定表」（见 3.3）
- 证据要求：**必须用 Trae 自带搜索工具**（系统 websearch / webfetch + research-web-search skill）寻找外部证据——原材料价格指数、行业价格战新闻、同行毛利率对比、管理层电话会/调研纪要；每条证据标注来源 + 时点；找不到证据的归因显式标注「证据不足，置信度 ≤6」
- 关键证据：外部来源 URL、同行财报、行业数据

9.3 数据逻辑一致性检查（挖不合逻辑处 + 追因）
- 逐项核对 8 项勾稽（表见模板 4.8）：营收 vs 经营现金流；应收 vs 营收；存货 vs 营业成本；归母净利 vs 扣非净利；毛利率 vs 单价/成本；净利润 vs 经营现金流；管理层归因表述 vs 数据；营收 vs 产能/销量
- 对每项不一致处标注「逻辑断裂点」，并追因（例：营收增但现金流降 → 放宽信用？票据结算增加？收入确认激进？）
- 管理层解释 vs 财务数据对照（管理层说的和数字是否吻合）
- 关键证据：三表、附注、MD&A 表述
```

**c. 输出结构调整**（重排第 4 章小节，章级编号不动，CrossValidator 引用的「第 9 章」不受影响）：

原：4.1 盈利能力 → 4.2 资产质量 → 4.3 负债与现金流 → 4.4 原文排雷 → 4.5 股东回报
新：4.1 盈利能力（含杜邦）→ **4.2 扣非净利润归因拆解（强制）** → **4.3 核心指标波动归因分析（强制，需外部证据）** → 4.4 资产质量 → 4.5 负债与现金流 → 4.6 原文排雷字段 → 4.7 股东回报与资本配置 → **4.8 数据逻辑一致性检查表（强制）**

**d. 精读摘要补充**：核心发现中增加「关键归因发现（含正反两方）」。

**e. 质量标准新增 3 条**：
- [ ] 4.2 扣非归因已填写（差额拆解到具体非经常性损益项 + 持续性判断 + 出处）
- [ ] 4.3 核心指标波动已归因，每条结论附外部证据（来源 + 时点）或显式标注「证据不足」

  | 现象 | 良性 | 恶性 |
  |------|------|------|
