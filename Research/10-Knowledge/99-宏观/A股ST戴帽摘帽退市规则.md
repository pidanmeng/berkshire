# A 股 ST 戴帽 / 摘帽 / 退市规则

> **规则时效**：截至 **2026-09-01** 有效。本笔记以交易所现行《股票上市规则》《交易规则》及监管文件为事实源，重大修订需更新本笔记。
> **用途**：ST 股票价值评价方法论（[[ST股价值评价方法论]]）的规则事实源；条款 ID（如 F1 / T1 / N1 / M1）供 ST 公司笔记 frontmatter 与调研流程引用。
> **置信度说明**：交易所官方原文直接引用的条款标「高」；监管口径归纳与市场解读标「中」；仅个案/自媒体来源的信息标「低」或不收录。

---

## 一、概念界定：ST 与 *ST

| 标识 | 全称 | 含义 | 监管意图 |
|------|------|------|---------|
| **ST** | 其他风险警示 | 公司存在经营/治理/合规异常，投资权益可能受损但尚未触及终止上市 | 提示风险、督促整改（非致命，可中途撤销） |
| ***ST** | 退市风险警示 | 公司触及财务类/规范类等与强制退市直接相关的指标，存在终止上市风险 | 警示退市风险、给出整改期 |
| **退市整理** | 退市整理期股票 | 已触及终止上市、进入退市整理期交易的股票 | 提供最后交易窗口后摘牌 |

> 规则要点：同时存在退市风险警示与其他风险警示的，简称冠以「*ST」。风险警示股票与退市整理股票统一进入**风险警示板**交易。

---

## 二、ST（其他风险警示）触发条件

> 条款 ID：**S 系列**（S1/S2/…）。ST 的核心是「非退市性的异常」——整改完成即可撤销，不强制盈利。

| ID | 触发情形 | 具体标准（主板） | 置信度 |
|----|---------|-----------------|:------:|
| S1 | **分红不达标**（2025 年新增） | 最近一个会计年度净利润与母公司未分配利润均为正，且最近 3 个会计年度累计现金分红 < 最近 3 年年均净利润 30% **且** 累计分红 < 5000 万元 | 高 |
| S2 | **财务造假梯度警示**（未达退市标准） | 证监会行政处罚/事先告知书认定年报财务指标（营收/利润总额/净利润/资产负债）存在虚假记载 | 高 |
| S3 | 资金占用（未达规范类退市程度） | 控股股东及其关联方非经营性占用资金，未按期整改或未达退市标准 | 中 |
| S4 | 内控缺陷 | 内部控制审计被出具否定意见/无法表示意见（未连续 2 年）等 | 中 |
| S5 | 违规担保、信披违规等 | 违规对外担保、重大信息披露违规等规范运作异常 | 中 |
| S6 | 持续经营能力存疑 | 主营业务停滞/停产、重大诉讼等导致持续经营不确定 | 中 |

> 注：S2 与 2024 新规「造假退市」形成梯度——造假被认定即 ST（无论金额），金额/年限达到 M1 标准则直接退市。创业板/科创板/北交所另有细则，见第四节。

---

## 三、*ST（退市风险警示）触发条件

> 条款 ID：**F 系列（财务类）** + **N 系列（规范类）**。*ST 直接挂钩强制退市指标，摘帽门槛显著高于 ST。

### 3.1 财务类（F 系列）——*ST 最常见来源

| ID | 触发情形 | 主板标准 | 创业板 | 科创板 | 置信度 |
|----|---------|---------|--------|--------|:------:|
| F1 | **组合指标** | 利润总额、净利润、扣非净利**孰低者为负** **且** 营收 < **3 亿元** | 营收 < **1 亿元** | 营收 < **0.5 亿元** | 高 |
| F2 | 净资产为负 | 最近一年期末净资产为负值 | 同左 | 同左 | 高 |
| F3 | 审计非标 | 年报被出具**无法表示意见**或**否定意见** | 同左 | 同左 | 高 |
| F4 | 追溯调整后触及 | 财务数据追溯调整后仍触及 F1-F3 | 同左 | 同左 | 高 |

> 注：2024 新规后组合指标在「净利润+营收」基础上**增加利润总额为负**的考察维度；营收门槛由 1 亿上调至 3 亿（主板）。

### 3.2 规范类（N 系列）——2024 新规新增

| ID | 触发情形 | 具体标准 | 置信度 |
|----|---------|---------|:------:|
| N1 | **资金占用** | 控股股东（无控股股东则为第一大股东）及其关联方非经营性占用资金余额 ≥ **2 亿元** 或占最近一期经审计净资产绝对值 **30%** 以上，被证监会责令改正但未按期整改 | 高 |
| N2 | **内控连续非标** | 连续 2 年财务报告内部控制被出具否定/无法表示意见（或第 3 年仍未消除） | 高 |
| N3 | **控制权无序争夺** | 控制权长期无序争夺导致投资者无法获取公司有效信息 | 高 |

### 3.3 其他

- **未按期披露定期报告**：未在法定期限披露年报/半年报且停牌超 2 个月 → *ST（后续规则衔接）。
- **重大违法类*ST 过渡**：重大违法退市情形（M 系列）依情形直接退市或先 *ST 过渡（见第六节）。

## 四、板块差异对照表

| 维度 | 主板（沪/深） | 创业板 | 科创板 | 北交所 |
|------|:-----------:|:------:|:------:|:------:|
| 有无 ST（其他风险警示） | ✅ | ✅ | ✅ | ❌ 仅 *ST |
| F1 组合指标营收门槛 | 3 亿元 | 1 亿元 | 0.5 亿元 | 财务类口径另定 |

## 五、摘帽规则（撤销风险警示）

> 条款 ID：**R 系列**。核心结论：***ST 必须等完整年报披露后才能申请，且须内控无保留；ST（无处罚类）可中途专项申请；有处罚类需满 12 个月**。

### 5.1 *ST 摘帽（摘星）——R1

| 环节 | 要求 |
|------|------|
| 前提（缺一不可） | ① 财务硬指标全达标：净资产为正、营收达标（主板 ≥3 亿）、净利润/扣非净利为正（对应 F1/F2 消除）；② 年报审计意见为标准无保留（非标消除）；③ **内控审计报告为无保留意见**（2024 新规硬要求，否则予以退市）；④ 资金占用/违规担保等规范问题清零 |
| 申请时点 | **唯一窗口：次年完整年报披露后（4 月 30 日前披露）5 个交易日内**向交易所提交申请。半年报/季报整改达标无效，规则只认完整年报 |
| 审核流程 | 交易所 5 个交易日内决定是否受理 → 受理后 10-15 个工作日内审核（可要求补充材料，补充时间不计入）→ 同意后**停牌 1 个交易日，次日撤销风险警示、恢复简称** |
| 超期不申请 | 大概率存在隐藏问题（非标未消/违规未清），摘帽预期落空 |

### 5.2 ST 摘帽（脱帽）——R2

| 情形 | 规则 |
|------|------|
| 无证监会处罚类（资金占用/违规担保/内控缺陷/账户冻结） | 整改全部结清 + 会计师出具专项核查/内控无保留鉴证报告 + 治理稳定运行一段时间后，**无需等年报，随时可申请**（月度/季度整改完成即可） |
| 证监会立案/行政处罚类（S2 等） | **锁定 12 个月**：自行政处罚决定书出具之日起满 12 个月才能提交摘帽申请 |
| 同时带 *ST + ST | **先摘星（满足年报财务条件）再脱帽**，不能只整改规范就全部撤销 |

### 5.3 摘帽通用限制（R3）

- 提交申请后交易所审核 5-15 个工作日，发问询函顺延；
- 需全套佐证材料：整改报告、会计师专项意见、独立董事意见、律师核查文件；
- 披露之日起 **5 个交易日内**提交申请（错过即视为放弃该轮）。

## 六、四类强制退市标准

> 条款 ID：**T 系列（交易类）/ F 系列（财务类，与*ST 衔接）/ N 系列（规范类）/ M 系列（重大违法类）**。

### 6.1 交易类（T 系列）

| ID | 指标 | 标准 | 置信度 |
|----|------|------|:------:|
| T1 | 面值退市 | 连续 20 个交易日收盘价 < **1 元** | 高 |
| T2 | 市值退市 | 连续 20 个交易日收盘总市值 < **5 亿元**（主板，原 3 亿；仅 B 股公司维持 3 亿；北交所 3 亿） | 高 |
| T3 | 成交量退市 | 连续 120 个交易日累计成交量 < 500 万股（沪深主板，原 90 日） | 高 |

### 6.2 财务类（F 系列，与 *ST 衔接）

| ID | 标准 |
|----|------|
| F1 | 组合指标：利润总额/净利润/扣非净利孰低为负 **且** 营收 <3 亿（主板）/1 亿（创业板）/0.5 亿（科创板），且下一年度仍未消除（即 *ST 后首年未摘帽） |
| F2 | 期末净资产为负，且下一年度仍未消除 |
| F3 | 年报无法表示/否定意见，且下一年度仍为无法表示/否定意见 |

> 机制：触及 F 系列 → *ST → 次年年报仍未达标/未摘帽 → 终止上市。

### 6.3 规范类（N 系列）

| ID | 标准 |
|----|------|
| N1 | 资金占用 ≥2 亿或净资产 30% + 被责令改正未按期整改 → 先停牌（≤2 个月）→ 仍不整改 → *ST → 仍不整改 → 退市 |
| N2 | 连续 2 年（及以上）内控否定/无法表示意见 |
| N3 | 控制权无序争夺导致信息获取障碍 |

### 6.4 重大违法类（M 系列）——2024 新规大幅收紧

| ID | 标准 | 置信度 |
|----|------|:------:|
| M1 | **财务造假退市**：① 1 年虚假记载金额 ≥ **2 亿元** 且占比 ≥ **30%**；② 连续 2 年虚假记载金额合计 ≥ **3 亿元** 且占比 ≥ **20%**；③ 连续 3 年及以上存在虚假记载 | 高 |
| M2 | 欺诈发行：IPO/重组文件虚假记载，影响上市条件 | 高 |
| M3 | 重大违法类退市公司**不得申请重新上市** | 高 |

> 重大违法退市适用标准以违法事实发生时的规则为准（新规发布前已发生的按旧标准判断，发布后按新标准）。

## 七、退市流程全图

```
触及退市标准（T/F/N/M 任一）
        │
        ▼
*ST 过渡（财务类/规范类给 1 年整改期）或直接终止（交易类/重大违法类）
        │
        ▼
终止上市决定公告 → 退市整理期（15 个交易日，最后 5 日不设涨跌幅限制）
        │
        ▼
摘牌 → 转入全国股转系统（老三板/新三板）挂牌转让
        │
        ▼
重新上市：财务类/规范类退市公司满足条件可申请；重大违法类不得重新上市
```

关键时间点：
- ***ST 起始**：年报披露后 1-3 个交易日内交易所实施；
- **退市整理期**：15 个交易日，届满摘牌（原 30 日，2020 改革后 15 日）；
- **退市整理股票适当性**：个人投资者需「50 万元资产 + 2 年投资经验」，首次买入需签退市整理股票风险揭示书；
- **风险警示股票适当性**：普通投资者首次买入需签署风险揭示书。

## 八、交易限制汇总

| 限制项 | 规则 | 置信度 |
|--------|------|:------:|
| 涨跌幅 | 主板 ST/*ST 与退市整理 **5%**；创业板/科创板 20%；北交所 30% | 高 |
| 单日买入上限 | 沪深：**50 万股**/单只/日（自然人，竞价+大宗+盘后合并计算，普通账户+信用账户合并）；北交所 20 万股。**豁免**：上市公司回购、5% 以上股东按已披露计划增持 | 高 |
| 委托方式 | 风险警示股票与退市整理股票**仅限限价委托** | 高 |
| 适当性 | 首次买入风险警示股票须签风险揭示书；退市整理股票另需 50 万资产 + 2 年经验 | 高 |
| 卖出 | 无数量限制 | 高 |

## 九、2024 退市新规要点与过渡期

| 改革点 | 内容 | 过渡期/适用 |
|--------|------|------------|
| 财务造假退市标准 | 金额+比例大幅下调（M1 三档） | 新规发布后发生的违法适用新标准；存量按原标准 |
| 规范类新增 3 项 | 资金占用（N1）、内控连续非标（N2）、控制权争夺（N3） | 资金占用/控制权类自新规发布之日起施行；内控非标以 **2024 年度**为第一个会计年度 |
| 财务类组合指标 | 营收门槛 1 亿 → 3 亿（主板）+ 增加利润总额为负维度 | **自 2024 年年报**开始适用；2024 年报触及 → *ST，2025 年末仍未达标才退市（约 1.5 年改善期） |
| 市值退市 | 3 亿 → 5 亿（主板） | 设 **6 个月过渡期** |
| 分红 ST | 分红不达标 → ST（S1） | 2025 年新增 |
| 内控无保留硬要求 | *ST 摘帽须内控无保留意见，否则退市 | 自新规施行后适用 |
| *ST 撤销条件收紧 | 撤销退市风险警示要求内控审计无保留 | 同上 |

> 监管导向：加大「僵尸空壳」「害群之马」出清力度、削减壳资源价值、从严打击规避退市与「炒壳」、坚决出清不具有重整价值的上市公司。
