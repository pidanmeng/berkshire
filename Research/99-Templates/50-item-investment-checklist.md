# 50 项投资决策检查清单（Investment Decision Checklist）

> **版本**: v1.0
> **灵感来源**: ai-berkshire/investment-checklist Skill + 四大师投资哲学
> **用途**: 每份最终报告（md+html）输出前，由 ReportWriter 手动逐项自检后附在报告末尾；也可用于 KnowledgeArchitect 在写入知识库时自检。
> **使用方式**:
> - 自动项（`[AUTO]`）可由 `research-quality-gate/scripts/investment-checklist-auto.ts` 脚本对报告文件跑自动检查
> - 手动项（`[MANUAL]`）必须由 Agent 结合调研结论逐项打钩，并留 1 行「依据」
> - **放行标准**：CRITICAL 级 ❌ ≤ 1 项，且无 CRITICAL "一票否决" 项（No-Go）触发

| 8 | IMPORTANT | [AUTO] InfoHunter 是否下载了**最近完整财年定期报告**（优先 ≥1 份年报 + 最近 1 期中报/季报，如有） | ⬜️ |  |

## 四、财务质量 & 估值（25-34）

|---|------|--------|------|--------------|

| 30 | IMPORTANT | [AUTO] 大额资产减值损失 / 净利润 > 30%（可能隐藏历史错误/粉饰）| ⬜️ |  |

| 32 | IMPORTANT | [MANUAL] **估值区间判断**：当前价 / 内在价值 = ?（需给出 3 种情景）| ⬜️ |  |
| 33 | NORMAL | [MANUAL] 行业历史估值分位：当前 PE/PB 处于历史 10 年的什么分位？ | ⬜️ |  |
| 34 | CRITICAL | [MANUAL] **安全边际条件**：在什么价/什么条件下才有足够安全边际？（无法给出=暂缓决策）| ⬜️ |  |
