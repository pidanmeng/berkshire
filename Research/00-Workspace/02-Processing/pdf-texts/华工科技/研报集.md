# 华工科技（000988）研报集

> 研报仅作辅助参考，核心结论以财报原文精读为准。

## 1. 开源证券 · 首次覆盖报告：三大业务共振，筑就AI光电领军企业（2025-11-19）

- 评级：**买入**（首次覆盖）
- 预测：2025-2027 归母净利润 19.6 / 25.5 / 32.6 亿元；对应 PE 36.9 / 28.3 / 22.2 倍
- 三大业务：激光加工（智能制造装备）/ 光联接+无线联接 / 传感器（敏感电子技术）
- 光模块：200G-800G 批量交付能力，卡位头部互联网厂商；自研 20G 光芯片及 1.6T 光模块方案；布局 3.2T；硅光、铌酸锂新材料；研发 CPO、LPO
- 传感器：压力传感器国产替代，车载传感器市占率提升，首次获飞行汽车定点；PTC 加热器获国际车企订单
- 智能装备：全球首台智能三维五轴激光切割装备、新一代激光落料设备；3D 打印（SLM）技术
- 风险提示：算力产业发展不及预期，新能源/船舶/消费电子发展不及预期，国际贸易风险

## 2. 太平洋证券 · 业绩稳步增长，AI光联接加速放量（2026-06-21）

- 评级：**买入**
- 2025 年报：营收 143.55 亿元（+22.59%），归母净利 14.71 亿元（+20.48%）
- 2026Q1：营收 42.66 亿元（+27.13%），归母净利 6.38 亿元（+55.76%），毛利率 19.81% 同比小幅下滑
- 分部（2025）：光电器件收入 60.97 亿元（+53.39%），占比 42.48%，最大增长引擎；激光加工装备及智能制造产线收入 36.36 亿元（+4.13%），毛利率 29.40%；敏感元器件收入 40.27 亿元（+9.78%），毛利率 24.46%
- 海外收入 20.10 亿元（+45.52%），占比 14.00%
- **2025 年经营活动现金流量净额 -11.27 亿元**（备货增长、固定资产投资）
- 产能：武汉光电子信息产业研创园一期、泰国海外高速光模块基地、孝感智能终端基地已投产
- 已实现 800G 硅光 LPO 系列和 1.6T 光模块全球第一梯队规模化交付；推出 1.6T LPO、3.2T NPO、3.2T CPO 光引擎及 400G/lane 光引擎
- 传感器：新能源及智能网联汽车市场国内市占率 70%，压力传感器销售增速超 100%
- 2026-04-13 已向港交所递交 H 股上市申请
- 预测：2026-2028 归母净利 24.71 / 33.34 / 40.58 亿元，EPS 2.46 / 3.32 / 4.04 元，对应 PE 72.25 / 53.55 / 43.99 倍
- 风险：订单落地节奏不及预期、光模块物料紧缺、行业竞争加剧

## 3. 国金证券 · 光模块业务营收翻倍，积极扩产备货（2026-05-05）

- 评级：**买入**
- 2026Q1：营收 42.66 亿元（+27.1%），**扣非归母净利 3.73 亿元（+20.51%）**，毛利率 19.8%（-0.7pct，产品结构升级期间产能良率爬坡）
- 光模块业务盈利同比增长约 120%；电信光模块收入占比 9.9%（-7.5pct），**数据中心光模块占比 60.5%（+14.6pct）**
- **800G 以上光模块 Q1 销售额同比 +13974%，环比 +229%**
- 1Q26 经营现金流 -11.27 亿元（-229.1%）；存货 36.89 亿元（+28.0%）；固定资产 30.95 亿元（+36.40%）；在建工程 2.71 亿元（+26.2%）
- 全链条：芯片（磷化铟/砷化镓/硅光三大平台全覆盖，国内唯一，另布局薄膜铌酸锂和量子点激光器）→ 器件 → 模块 → 子系统
- 预测：2026/2027/2028 营收 247.41 / 411.02 / 605.09 亿元，归母净利 22.77 / 27.17 / 34.09 亿元，PE 51 / 43 / 34 倍
- 风险：AI 发展不及预期、市场竞争加剧、赴港上市进度不及预期
